# Basalt Community

Docs and community hub for [Basalt](https://basaltapp.com), a privacy-first budgeting app that stores your data as plain YAML files on your own disk instead of in someone else's database.

This is the public place to read the docs and to submit bug reports and feature requests. If you hit a problem or want to see something added, this is where the community reports it and suggests what Basalt should do next. File an issue any time; see [below](#reporting-a-bug-or-requesting-a-feature).

## Docs

[Vault File Format](docs/vault-file-format.md) covers the on-disk format of a Basalt vault: directory layout, YAML conventions, entity schemas (accounts, categories, transactions, budgets), and legacy/compatibility notes. Useful if you want to read, script against, or sync your vault outside the app.

## Reporting a bug or requesting a feature

Use [Issues](../../issues) on this repo. Include:

- What you expected vs. what happened (for bugs)
- Your platform (desktop/mobile, OS)
- Your app version numbers: go to the bottom of the Preferences page in Basalt and copy the versions line
- Steps to reproduce, if applicable

Please don't include vault contents, account numbers, or other financial data in issues. This repo is public.
